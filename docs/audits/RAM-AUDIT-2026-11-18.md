# Auditoria de RAM — MD-DOOM64KB (branch exp-manifold-m14-e1m1, base r079 + armas v10b)

Medido em MAME (ROM flat de cada mapa, 2400 frames de caminhada/tiro scriptados) + `nm` dos `rom.out`. RAM útil = 64 KB (0xE0FF0000–0xE1000000).

O sistema de armas inteiro usa < 150 B de RAM; os tiles ficam em ROM (.wpndata/.wpndata2) e só passam pela VRAM — por isso reduzir os sprites das armas não libera RAM.

## Onde recuperar RAM (estimativas)
1. tile_buf do console: ~672 B (não usado com MANIFOLD_NO_TEXT=1) — risco baixo.
2. NUM_CLIP_BUFS 16→12 (prof. máx. observada 10): ~1,3 KB — validar nos 9 mapas.
3. decorations/objects dimensionados por mapa (junta com remover limites 255/63): 1–2,5 KB.
4. Buffers de fade (1.032 B) alocados sob demanda: ~1 KB — risco médio.
5. Estrutural: framebuffers (36,9 KB) — só reduzindo viewport/pitch.
Cada KB liberado vira margem de pilha para a guarda e menos cortes de portal.

Limites da medição: caminhada scriptada a partir do spawn (não jogo completo); "fundo da pilha" inclui qualquer escrita na folga; mapa↔índice do flat confirmado pelo tamanho do heap (E1M8 menor, E1M6 maior).
